# AMML Ranking Competition 2026

Ранжирование русскоязычных отрывков по релевантности запросу. Лучший сабмит команды, **AMML Rank Gated** (ID `58606250`), получил **0,962375 NDCG@10** на публичном лидерборде Kaggle.

- [Страница соревнования и данные](https://www.kaggle.com/competitions/amml-ranking-competition-2026/data)
- [Финальный запуск на Kaggle](https://www.kaggle.com/code/tomakoch/amml-rank-gated)

## Воспроизведение

1. Склонируйте репозиторий и перейдите в его корень.
2. Скачайте оригинальный `amml-ranking-competition-2026.zip` во вкладке **Data** после входа в аккаунт с доступом к соревнованию. Положите архив рядом с ноутбуком. Можно также указать переменную `AMML_DATA` с путём к архиву или к каталогу с `train.csv`, `test.csv` и `sample_submission.csv`.
3. Установите зависимости в среду Python 3.13 и выполните ноутбук.

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter nbconvert --to notebook --execute solution.ipynb \
  --output-dir=outputs --output=solution.executed.ipynb \
  --ExecutePreprocessor.timeout=900
```

Команда сохраняет итоговый CSV в `outputs/rank_gated_submission.csv` и отчёты по валидации в `outputs/gated_*.csv`. Переменная `AMML_OUTPUT` задаёт другой каталог для CSV. Запуск использует CPU.

Ноутбук заново очищает исходные тексты, строит признаки, обучает финальные модели CatBoost, проверяет варианты поправки на валидации, применяет зафиксированную конфигурацию `gated_medium` и формирует 13 507 предсказаний в порядке шаблона Kaggle. В одной ячейке сохранены промежуточные числовые признаки и оценки моделей, включая выход предыдущего этапа AMML Robust Ranking. Благодаря этому не нужен доступ к приватным ноутбукам команды или повторный GPU-инференс. Исходные тексты, разметка и CSV лучшего сабмита в репозиторий не входят. Это воспроизведение финального этапа из зафиксированных промежуточных результатов.

## Что пробовали

| Этап | Решение и наблюдение |
| --- | --- |
| Очистка данных | Нормализовали Unicode и HTML, убрали невидимые символы, исправили распознаваемые случаи испорченной кириллицы и смешения алфавитов. Для длинных отрывков выбирали окно с учётом слов запроса. |
| Оценки моделей | Использовали несколько представлений текста для Jina Reranker v3.5. Добавили Qwen3-Reranker-8B и вспомогательные семантические оценки BGE, Horizon и Lamar. Сопоставляли оценки внутри одного запроса. |
| CatBoost и финальная поправка | Обучили попарный ранкер CatBoost. Второй ранкер учился на парах с весами, зависящими от изменения DCG@10 и близости оценок. Его поправка сильнее действует там, где оценки двух лидеров близки. Сравнили две силы поправки и перестановку только первых трёх отрывков. |
| Проверка устойчивости | Оценивали NDCG@10 по целым группам запросов, использовали два dev-разбиения и отдельный набор из 350 запросов, включая 129 запросов к новым статьям. Выбранный вариант `gated_medium` дал +0,00318 на отложенных запросах и +0,00413 на новых статьях по сравнению с базой этого этапа. |
| Альтернативы | Дообученный на трудных парах Qwen 0.6B немного улучшился сам по себе, но снизил метрику ансамбля. Смесь с 5% Yuanbao 8B дала 0,962215 на Public. Перестановка лидеров по согласию Yuanbao 4B и 8B проиграла на обоих dev-разбиениях. |

Public NDCG@10 рассчитана Kaggle на скрытых ответах. Ноутбук вычисляет валидационные метрики и восстанавливает файл для отправки.

При проверочном запуске на macOS с Python 3.13 порядок всех 13 507 отрывков внутри запросов совпал с исходным сабмитом. Числовые оценки могут отличаться между средами.
