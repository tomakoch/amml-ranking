# AMML Ranking Competition 2026

Ранжирование русскоязычных отрывков по релевантности запросу. Лучшее решение — **AMML Rank Gated**, **0,962375 NDCG@10** на Public. 

## Эксперименты

- **Очистка текста.** Нормализовала Unicode и HTML, исправляла повреждённую кириллицу. Для длинных отрывков выбирала окно по словам запроса.
- **Ансамбль.** Сравнила несколько представлений текста для Jina v3.5. В итоговом стеке объединила оценки Jina и Qwen3-Reranker-8B в пропорции 80/20 и использовала признаки BGE, Horizon и Lamar.
- **Финальный ранкер.** Обучила попарные модели CatBoost. Поправка сильнее меняла порядок там, где оценки двух лидеров были близки. На отложенных запросах она дала **+0,00318 NDCG@10**, на запросах к новым статьям — **+0,00413**.
- **Альтернативы.** Дообучение Qwen 0.6B на трудных парах снизило качество ансамбля. Смесь с 5% Yuanbao 8B дала **0,962215** на Public. Перестановка лидеров по согласию Yuanbao 4B и 8B ухудшила оба dev-разбиения.
